▸ Como exportar e preparar os dados a partir do KoboToolbox

Opção recomendada — ficheiro único: no KoboToolbox, Projeto → Download data → Export, formato XLSX. O ficheiro gerado tem duas folhas — uma por área sanitária (submissão) e outra "sites" (uma linha por local, grupo repetido) — e pode ser carregado diretamente aqui em "Carregar exportação Kobo (.xlsx)". O painel reconhece automaticamente as colunas, quer o export use os nomes das perguntas, quer os seus rótulos em português (como no export padrão do Kobo).

Alternativa CSV: exportar separadamente o CSV principal e o CSV do grupo repetido "sites" (opção "Include groups in headers" não é necessária) e carregá-los nos dois campos CSV.

Atualização: repita a exportação sempre que quiser e recarregue aqui os ficheiros — tudo é recalculado instantaneamente. Para uma atualização verdadeiramente automática, use a opção "Ligação direta à API Kobo" acima.
Ligação direta à API do KoboToolbox — liga o painel diretamente aos dados do servidor, com atualização automática periódica, sem precisar de voltar a exportar manualmente.
O token fica apenas na memória deste separador do navegador (ou gravado localmente só neste computador, se marcar "lembrar"). Nunca é enviado para outro lado além do servidor Kobo indicado. Se a ligação falhar (erro de rede/CORS), o servidor Kobo pode não permitir pedidos diretos do navegador — nesse caso, use a exportação XLSX acima, ou a ligação Power Query descrita no guia Power BI.
